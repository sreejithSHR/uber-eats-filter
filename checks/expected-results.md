# Expected-results check table

Worked out by hand, row by row, against all 40 listings in `data/restaurants.csv`. The filter code is judged against this table, so it was not generated by Claude Code.

**Rules used in every row**
- **Exactly 30 minutes counts.** The delivery chip is "30 min or less": a restaurant stays when `delivery_time_min <= 30`.
- Exactly 4.0 counts for 4.0+ (`rating >= 4.0`).
- Groups combine with AND; price tiers inside the price group combine with OR.
- Vegan counts as vegetarian (my call, flagged): Chiang Mai Noodle Bar, Sprout & Seed and Tofu Temple are vegan but marked not vegetarian. Without this rule, row 1 would be 9, not 11.
