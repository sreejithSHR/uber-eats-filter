# Expected-results check table

Worked out by hand, row by row, against all 40 listings in `data/restaurants.csv`. The filter code is judged against this table, so it was not generated by Claude Code.

**Rules used in every row** (the same definitions the filter code uses)
- **Exactly 30 minutes counts.** The delivery chip is "30 min or less": a restaurant stays when `delivery_time_min <= 30`.
- Exactly 4.0 counts for 4.0+ (`rating >= 4.0`).
- Groups combine with AND; price tiers inside the price group combine with OR.
- Dietary chips read the data's yes/no columns exactly as written: Vegetarian means `is_vegetarian = true`.

**Open data question (not applied):** Chiang Mai Noodle Bar, Sprout & Seed and Tofu Temple are marked vegan but not vegetarian. That looks like a data error, but the definition belongs to whoever owns the restaurant data, so it is raised with them rather than patched here. If they confirm vegan implies vegetarian, the data is corrected at the source and rows 1 to 3 gain those names.
